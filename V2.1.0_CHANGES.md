## Changes by Category

### 🔧 REQUIRED FIXES

#### 1. Add `se_new` Parameter to `predict()` (Issue 1)
**Problem**: Method hardcoded `np.median(se_train)` for new study SEs, preventing users from specifying expected precision.

**Solution**:
```python
def predict(
    self,
    X: Union[np.ndarray, pd.DataFrame],
    se_new: Optional[Union[float, np.ndarray]] = None,  # NEW!
    return_std: bool = False,
    return_samples: bool = False,
    include_tau: bool = True
) -> ...:
```

**Features**:
- `se_new=None`: Default behavior (uses median of training SEs)
- `se_new=0.15`: Scalar for all new studies
- `se_new=[0.1, 0.2, 0.15]`: Array matching number of new studies
- Validation: Raises error if array length doesn't match X rows

**Impact**: Users can now specify precision of future studies based on planned sample sizes.

**Files Modified**: `bart_meta_regression.py:277-336`

---

#### 2. Add Convergence Status Tracking (Issue 3)
**Problem**: Convergence diagnostics issued warnings but provided no mechanism to fail or retry.

**Solution**:
- **New parameter** in `fit()`:
  ```python
  convergence_check: str = 'warn'  # 'warn', 'error', 'ignore'
  ```
- **New attribute**: `self.converged` (True/False/None)
- **New method**: `_check_convergence()` evaluates R-hat > 1.01
- **Warnings** in `predict()` when `self.converged is False`

**Behavior**:
```python
# Warn but continue (default)
bart.fit(X, y, se, convergence_check='warn')

# Raise RuntimeError if convergence fails
bart.fit(X, y, se, convergence_check='error')

# Skip convergence checking
bart.fit(X, y, se, convergence_check='ignore')
```

**Impact**: Users have explicit control over convergence handling, and downstream methods warn about unreliable predictions.

**Files Modified**:
- `bart_meta_regression.py:119` (attribute initialization)
- `bart_meta_regression.py:130` (fit() parameter)
- `bart_meta_regression.py:278` (convergence check in fit())
- `bart_meta_regression.py:707-752` (_check_convergence() method)
- `bart_meta_regression.py:326-331` (warning in predict())

#### 3. Add Sample Size Recommendation Caveats (Concern 1)
**Problem**: Recommendation "k ≥ 30" was too simplistic; depends on heterogeneity and effect size variability.

**Solution**: Added comprehensive caveats to `power_analysis.py`:

```
IMPORTANT CAVEATS:
- Low heterogeneity (I² < 25%): k ≥ 20 may suffice
- Moderate heterogeneity (I² 25-75%): k ≥ 30 recommended
- High heterogeneity (I² > 75%): k ≥ 50 recommended
- These thresholds also depend on signal strength (effect size variability)
- With k < 20: BART is NOT recommended; use WLS instead
```

**Impact**: Users understand that sample size requirements vary by context.

**Files Modified**: `power_analysis.py:403-432`

#### 4. Add Computational Cost-Benefit Documentation (Concern 2)
**Problem**: README lacked clear guidance on when BART's computational cost is justified.

**Solution**: Added comprehensive "Computational Considerations" section to README with:

**Content**:
1. **Runtime Performance**: BART (~60s) vs WLS (~0.2s) vs GAM (~1-2s)
2. **When BART is Worth It**:
   - ✅ Non-linear dose-response
   - ✅ Unknown interactions
   - ✅ Variable selection needed
   - ⚠️ NOT for k<20, simple linear, time-sensitive
3. **Optimization Tips**: Reduce n_trees/n_draws, use method='inclusion'
4. **Performance Table**: Runtime vs k and p
5. **Recommended Workflow**: Exploration → Refinement → Final analysis

**Impact**: Users can make informed decisions about method choice.

### 🚀 STRONGLY RECOMMENDED FIXES

#### 5. Optimize Partial Dependence Computation (Issue 2)
**Problem**: Original implementation called `predict()` inside nested loops (5,000+ calls for typical settings).

**Original**:
```python
for sample_idx in range(100):
    for grid_idx in range(50):
        X_pd = self.X_train.copy()
        X_pd[:, feature_idx] = grid_val
        pred = self.predict(X_pd).mean()  # Expensive!
        pd_samples[sample_idx, grid_idx] = pred
```

**Optimized**:
```python
# Create stacked data: (n_grid × n_studies, n_features)
X_stacked = np.tile(self.X_train, (len(grid_values), 1))
X_stacked[:, feature_idx] = np.repeat(grid_values, n_train)

# Single predict() call
pred_results = self.predict(X_stacked, return_samples=True)

# Reshape and average
pred_samples_reshaped = pred_samples_all.reshape(
    n_posterior_samples, len(grid_values), n_train
)
pd_samples = pred_samples_reshaped.mean(axis=2)  # Average over studies
```

**Performance**: ~10-50× speedup depending on `grid_resolution`
- Old: ~5 minutes per feature (grid_resolution=50)
- New: ~10-30 seconds per feature

**Impact**: Makes partial dependence plots practical for exploratory analysis.

**Files Modified**: `bart_meta_regression.py:565-618`
